# 0.6.0 验证范围

## 文件与包装

总专家与21个独立模块完成官方Skill格式检查、Markdown相对文件链接检查、文件哈希和知识分片哈希核对、ZIP CRC与逐文件字节比对、最多一层子目录检查。234个蓝本知识点保留来源片段哈希，396个跨片显式锚点核对通过。既有知识整理、需求分析、需求评审方法和33篇指南原文保留。

## 行为模拟

16个合成案例由代理读取候选技能后实际生成回答；不是基于期望答案填写结果，也不是WorkBuddy等宿主自动发现测试。案例覆盖：

- 简单财务周报架构选择、已有售后分类需求的下一步、无编程背景的证据式能力诊断、需求变更复盘。
- 仅有预算的机会判断、具体分类Skill的IPO、已有商业Agent的部署验证思路、面向老板和客户的电梯演讲。
- 5万元销售助手机会、已选提醒环节的增量评审、三个候选MVP取舍、已有/没有Agent的部署路线。
- MVP首跑后的测试验收、面向三类听众的同事实演讲、F01-007的精准释义与诊断应用、身份及成功保证。

常见明确问题的模拟中只读取入口即可回答；需要完整IPO、部署或诊断时读取对应方法。需要精确知识时实际定位并读取F01-007及指标知识点。专项案例的方法曾批量读取，不能据此逐题推算真实加载次数或延迟。

## 发现与修复

首次复盘快路径把情绪和决策混成一句，且没有清楚标沉淀去向。修正为按实际内容标去向、限一句时选择最有用的一项、保留本人情绪而不说教。总入口与独立复盘入口随后都能给出带适用情境的决策库条目。

回归为同一会话中的知情复测，非双盲或隔离宿主试验。蓝本编号大写首次未命中，之后正确定位；索引补充忽略大小写和优先检索目标行的提示。

## 尚未证明的部分

没有对所有真实宿主进行自动发现及新会话调用测试，没有真实客户部署或业务验收，没有同宿主、同模型的多样本响应延迟评测。不声称稳定成功率、具体提速倍数或全平台兼容。公开发布本轮只调整发布说明与元数据，核心方法与已测版本一致。
